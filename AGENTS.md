This is a personal project building a simple math game.
Rules of the game are described in game_rules.md

The primary goal of the project is to build ML model which can play this game well.
This is context, not permission to expand the requested task.

=== LAYOUT ===

./engine/ - contains game engine logic.
./runners/ - contains runners of the game in various environments
./agents/skills/ - skills useful in this project

=== AGENTS.md/ CLAUDE.md ===

Scan all project tree for AGENTS.md/CLAUDE.md files.
Those files apply to the directory it's located in and
all nested directories unless nested rules override them.
